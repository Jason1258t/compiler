# Спецификация языка DotScript

## Введение

DotScript — строго типизированный императивный язык программирования с процедурным стилем. Программа на DotScript состоит из одного файла с исходным кодом.

Ключевые особенности:

1. Точкой входа является начало файла: инструкции, записанные вне функций, выполняются по порядку.
2. Поддерживаются следующие типы данных:
    - `int` (32-битное целое со знаком);
    - `str` (строка);
    - `bool` (логическое значение);
    - массивы `T[]`: литерал массива `[1, 2, 3]`;
    - структуры `struct`.
3. Переменные объявляются явно с помощью `let`.
4. Ввод и вывод выполняются встроенными функциями `print`, `println`, `readInt` и `readStr`.

Связь с другими языками:

1. DotScript относится к C-подобным языкам: блоки заключаются в фигурные скобки, инструкции завершаются символом `;`.
2. Ключевые слова `let` и `fn` и запись типа после имени заимствованы из Rust и TypeScript: `let x: int`, `fn sum(a: int): int`.
3. Выполнение программы с начала файла без функции `main` заимствовано из Python и JavaScript.
4. Названия типов `int`, `str` и `bool` заимствованы из Python.

## Лексика

1. Идентификатор (`identifier`) — это последовательность букв английского алфавита, цифр и символов подчёркивания "_", которая не начинается с цифры.
2. Ключевые слова — это последовательности букв, зарезервированные для однозначности синтаксических правил, они не являются идентификаторами.
3. Регистр идентификаторов и ключевых слов имеет значение: `value` и `Value` — разные идентификаторы, `While` — идентификатор, а не ключевое слово.
4. Имена встроенных функций — обычные идентификаторы, а не ключевые слова.
5. Литералы целых чисел (`integer_literal`) — это последовательность десятичных цифр:
    - Литерал может начинаться с 0, ведущие нули не влияют на значение: `007` обозначает число 7;
    - Литералы не содержат знак: `-12` — это оператор `-` и литерал `12`;
    - Не допускаются литералы целых чисел, значение которых превышает 2147483647.
6. Литералы строк — это последовательность символов, возможно пустая, заключённая в двойные кавычки `"`:
    - Между кавычками допускаются любые символы Unicode, кроме `"`, `\`, LF и CR, а также escape-последовательности;
    - Escape-последовательность начинается с символа `\`, допускаются только последовательности из таблицы ниже.
7. Литералы логического типа — это ключевые слова `true` и `false`.
8. Из нескольких подходящих лексем выбирается самая длинная: `<=` — это один оператор, а не `<` и `=`.
9. Комментарии и пробельные символы могут появляться между лексемами и игнорируются при разборе.
10. Однострочные комментарии начинаются с `//` и продолжаются до символа LF или CR либо до конца файла.
11. Многострочные комментарии начинаются с `/*` и заканчиваются на ближайшем `*/`, вложенные комментарии не допускаются.
12. Внутри литерала строки пробел, табуляция и последовательности `//`, `/*`, `*/` являются частью строки.

Список пробельных символов:

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

Список escape-последовательностей:

| Последовательность | Символ                        | Код ASCII |
| ------------------ | ----------------------------- | --------- |
| `\n`               | Перенос строки (LF)           | 0x0A      |
| `\r`               | Возврат каретки (CR)          | 0x0D      |
| `\t`               | Горизонтальная табуляция (HT) | 0x09      |
| `\"`               | Двойная кавычка               | 0x22      |
| `\\`               | Обратная косая черта          | 0x5C      |

Список ключевых слов: `bool`, `else`, `false`, `fn`, `if`, `int`, `let`, `return`, `str`, `struct`, `true`, `while`.

Список лексем, используемых в роли операторов выражений: `=`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `&&`, `||`, `!`, `+`, `-`, `*`, `/`, `%`, `.`

Список прочих лексем: `[`, `]`, `(`, `)`, `{`, `}`, `,`, `;`, `:`

К ошибке лексического разбора также приводят:

1. Символ, с которого не начинается ни одна лексема, например `@`, `#` или `$`.
2. Одиночный символ `&` или `|`.
3. Литерал строки без закрывающей кавычки.
4. Многострочный комментарий без завершающего `*/`.

## Синтаксис

Грамматика описывает подмножество языка, реализованное на текущей итерации: программа из инструкций-выражений над целыми числами. Терминальные символы `identifier` и `integer_literal` описаны в разделе «Лексика», остальные терминалы записаны в кавычках.

```ebnf
(* Программа — последовательность инструкций, выполняемых с начала файла *)
program = { statement } ;

statement = expression , ";" ;

expression = additive_expression ;

additive_expression = multiplicative_expression , { ( "+" | "-" ) , multiplicative_expression } ;

multiplicative_expression = unary_expression , { ( "*" | "/" | "%" ) , unary_expression } ;

unary_expression = "-" , unary_expression
                 | primary_expression ;

primary_expression = integer_literal
                   | function_call
                   | "(" , expression , ")" ;

function_call = identifier , "(" , [ argument_list ] , ")" ;

argument_list = expression , { "," , expression } ;
```

Операторы выражений, от высшего приоритета к низшему:

| Приоритет | Операторы          | Описание                                  | Ассоциативность |
| --------- | ------------------ | ----------------------------------------- | --------------- |
| 1         | `f(...)`, `( )`    | Вызов функции, группировка                | —               |
| 2         | `-` (унарный)      | Смена знака                               | Правая          |
| 3         | `*`, `/`, `%`      | Умножение, деление, остаток от деления    | Левая           |
| 4         | `+`, `-`           | Сложение, вычитание                       | Левая           |

## Семантика выражений

1. Инструкции выполняются по порядку, начиная с первой инструкции файла.
2. Значение выражения-инструкции отбрасывается.
3. Операнды и аргументы вычисляются слева направо.
4. Все вычисления выполняются над 32-битными целыми числами со знаком.
5. Деление `/` округляет результат к нулю: `7 / 2` равно `3`, `-7 / 2` равно `-3`.
6. Знак остатка `%` совпадает со знаком делимого: `-7 % 2` равно `-1`.

К ошибке выполнения приводят:

1. Деление или взятие остатка от деления на ноль.
2. Переполнение: результат операции не помещается в 32-битное целое со знаком.
3. Вызов неизвестной функции или вызов функции с неверным числом аргументов.
4. Использование результата функции, которая не возвращает значения, например `1 + print(2)`.
5. Ошибка ввода: ввод закончился или строка не является целым числом.

## Встроенные функции

| Функция               | Описание                                                                     |
| --------------------- | ---------------------------------------------------------------------------- |
| `print(x: int)`       | Выводит число без переноса строки, не возвращает значения                    |
| `println(x: int)`     | Выводит число и перенос строки LF, не возвращает значения                    |
| `readInt(): int`      | Читает строку из ввода и возвращает записанное в ней целое число со знаком   |
| `abs(x: int): int`    | Возвращает модуль числа                                                      |
| `min(a: int, b: int): int` | Возвращает меньшее из двух чисел                                        |
| `max(a: int, b: int): int` | Возвращает большее из двух чисел                                        |

Строка, прочитанная `readInt`, может содержать пробельные символы в начале и в конце.

## Выполнение программы

1. Интерпретатор принимает путь к файлу с исходным кодом первым аргументом командной строки.
2. Ввод программы читается из стандартного потока ввода, вывод записывается в стандартный поток вывода.
3. При лексической, синтаксической ошибке или ошибке выполнения интерпретатор прекращает работу, выводит сообщение об ошибке в стандартный поток ошибок и завершается с ненулевым кодом возврата.
4. Программа выполняется по мере разбора, поэтому вывод инструкций, предшествующих ошибке, сохраняется.
