# Спецификация языка DotScript

## Введение

DotScript — строго типизированный императивный язык программирования с процедурным стилем. Программа на DotScript состоит из одного файла с исходным кодом.

Ключевые особенности:

1. Точкой входа является начало файла: инструкции, записанные вне функций, выполняются по порядку.
2. Поддерживаются следующие типы данных:
    - `int` (32-битное целое со знаком);
    - `str` (строка);
    - `bool` (логическое значение);
    - массивы `T[]`;
    - структуры `struct`.
3. Переменные объявляются явно с помощью `let`.
4. Ввод и вывод выполняются встроенными функциями `print`, `println`, `readInt` и `readStr`.

Связь с другими языками:

1. DotScript относится к C-подобным языкам: блоки заключаются в фигурные скобки, инструкции завершаются символом `;`.
2. Ключевые слова `let` и `fn` и запись типа после имени заимствованы из Rust и TypeScript: `let x: int`, `fn sum(a: int): int`.
3. Выполнение программы с начала файла без функции `main` заимствовано из Python и JavaScript.
4. Названия типов `int`, `str` и `bool` заимствованы из Python.

## Лексика

1. Идентификатор — это последовательность букв английского алфавита, цифр и символов подчёркивания "_", которая не начинается с цифры.
2. Ключевые слова — это последовательности букв, зарезервированные для однозначности синтаксических правил, они не являются идентификаторами.
3. Регистр идентификаторов и ключевых слов имеет значение: `value` и `Value` — разные идентификаторы, `While` — идентификатор, а не ключевое слово.
4. Имена встроенных функций — обычные идентификаторы, а не ключевые слова.
5. Литералы целых чисел — это последовательность десятичных цифр:
    - Литерал может начинаться с 0, ведущие нули не влияют на значение: `007` обозначает число 7;
    - Литералы не содержат знак: `-12` — это оператор `-` и литерал `12`;
    - Не допускаются литералы целых чисел, значение которых превышает 2147483647.
6. Литералы строк — это последовательность символов, возможно пустая, заключённая в двойные кавычки `"`:
    - Между кавычками допускаются любые символы Unicode, кроме `"`, `\`, LF и CR, а также escape-последовательности;
    - Escape-последовательность начинается с символа `\`, допускаются только последовательности из таблицы ниже.
7. Литералы логического типа — это ключевые слова `true` и `false`.
8. Из нескольких подходящих лексем выбирается самая длинная: `<=` — это один оператор, а не `<` и `=`.
9. Комментарии и пробельные символы могут появляться между лексемами и игнорируются при разборе.
10. Однострочные комментарии начинаются с `//` и продолжаются до символа LF или CR либо до конца файла.
11. Многострочные комментарии начинаются с `/*` и заканчиваются на ближайшем `*/`, вложенные комментарии не допускаются.
12. Внутри литерала строки пробел, табуляция и последовательности `//`, `/*`, `*/` являются частью строки.

Список пробельных символов:

| Символ                        | Код ASCII |
| ----------------------------- | --------- |
| Пробел (SP)                   | 0x20      |
| Горизонтальная табуляция (HT) | 0x09      |
| Перенос строки (LF)           | 0x0A      |
| Возврат каретки (CR)          | 0x0D      |

Список escape-последовательностей:

| Последовательность | Символ                        | Код ASCII |
| ------------------ | ----------------------------- | --------- |
| `\n`               | Перенос строки (LF)           | 0x0A      |
| `\r`               | Возврат каретки (CR)          | 0x0D      |
| `\t`               | Горизонтальная табуляция (HT) | 0x09      |
| `\"`               | Двойная кавычка               | 0x22      |
| `\\`               | Обратная косая черта          | 0x5C      |

Список ключевых слов: `bool`, `else`, `false`, `fn`, `if`, `int`, `let`, `new`, `return`, `str`, `struct`, `true`, `while`.

Список лексем, используемых в роли операторов выражений: `=`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `&&`, `||`, `!`, `+`, `-`, `*`, `/`, `%`, `.`

Список прочих лексем: `[`, `]`, `(`, `)`, `{`, `}`, `,`, `;`, `:`

К ошибке лексического разбора также приводят:

1. Символ, с которого не начинается ни одна лексема, например `@`, `#` или `$`.
2. Одиночный символ `&` или `|`.
3. Литерал строки без закрывающей кавычки.
4. Многострочный комментарий без завершающего `*/`.
